# Color Clash LAN (Android)

A local Wi‑Fi multiplayer card game inspired by classic color-and-number shedding games.

## How it works
- Install the APK on one Android phone.
- The app starts a local HTTP game server on port 8765.
- It shows the LAN URL and a QR code.
- Other players open the URL in their browser while connected to the same Wi‑Fi.
- 2–8 players, room code, 7-card deal, skip, reverse, +2, wild and +4.

No internet is needed during play.
